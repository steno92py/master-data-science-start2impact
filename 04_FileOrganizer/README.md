## Contenuto

Organizzazione dei file per tipologia, riepiloghi e interfaccia a riga di comando con argparse.

**Strumenti:** Python, NumPy.

## Consultazione e riproduzione

Il [notebook](progetto/fileorganizer.ipynb) e lo [script argparse](progetto/addfile_argparse.py) corrispondono byte per byte ai membri dello ZIP approvato. Eseguire lo script con `--help` per i parametri. Usare una copia dei file di esempio: il programma sposta i file. Gli esempi audio restano nel solo archivio locale.
