# Soddisfazione dei passeggeri aerei — Stefano Nocco

Analisi del dataset Airline Passenger Satisfaction: esplorazione, trattamento dei valori mancanti, codifica delle variabili e confronto di modelli di classificazione.

- [Notebook](versione_git/Stefano%20Nocco%20PROGETTO%20FINALE%202.ipynb): copia per Git con le 135 celle originali, senza output.
- `train.csv` e `test.csv`: 103.904 e 25.976 righe.
- [Recap del progetto](RECAP.md) e [note metodologiche](NOTE_METODOLOGICHE.md).
- [Analisi esplorativa di supporto](materiali_supporto/Analisi%20Esplorativa%20dei%20Dati%20di%20Soddisfazione%20dei%20Passeggeri.pdf).

Per eseguire il notebook, usare questa cartella come directory di lavoro, così che i CSV siano disponibili nei percorsi relativi. La [guida alla riproducibilità](../../docs/RIPRODUCIBILITA.md) descrive il contesto degli ambienti storici.

Le metriche riportate nel testo provengono dall’esecuzione originale. Le note metodologiche ne esplicitano i limiti, inclusi preprocessing prima della cross-validation e uso dei ritardi effettivi nel modello chiamato “pre-volo”.
