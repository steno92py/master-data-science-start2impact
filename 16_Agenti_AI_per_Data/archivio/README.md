# Prototipo storico

Data Companion è conservato localmente in prototipo_data_companion. Per il progetto corrente usare [EcoBot](../ecobot/README.md).

## Materiali riuniti per corso

`pacchetti_preparatori/` raccoglie i tre ZIP precedenti, con suffissi `DA_VALIDARE`, e il relativo manifest storico. Il pacchetto finale è separato in `../consegna/pacchetto_riservato/`. Gli originali sono stati spostati senza modificarne i byte.
