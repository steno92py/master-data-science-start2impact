# Agenti AI per Data — EcoBot

Progetto di Stefano Nocco per analizzare produzione solare e consumi domestici. Python esegue i calcoli e valida i dati; l’agente LangChain usa strumenti dedicati e presenta i risultati in una chat Streamlit.

La cartella [ecobot](ecobot/README.md) contiene notebook, sorgenti, dataset sintetici, grafici, test e documentazione. Il [notebook](ecobot/agent.ipynb) conserva anche gli output delle verifiche.
